# (팀 미션) 뉴스 요약 자동화 #  

------------  
## ⭐  기획서  ⭐   
매일 수많은 뉴스가 쌓이는 정보중에서 "내가 정말 놓치면 안 되는 중요한 키워드"나 "특정 주제"가 포함된 정보들을 요약된 내용을 모아서 볼 수 있는 시나리오입니다.  

✅ 목표  
*RSS 피드에서 자동으로 뉴스를 수집하고, AI로 요약한 후, 노션 데이터베이스에 저장하는 완전 자동화 워크플로우 구축*  
 
------------  

### 📌  역할 분담 

| 데이터 소스& 트리거 | AI 요약 담당<br>(AI 프롬프트 엔지니어)  | 협업 도구 연동 | 통합& 품질 관리 |  
| :---: | :---: | :---: | :---: |  
| 민미경 | 김서영 | 유주현 | 민미경 |  
| RSS 피드 수집 구조 설계 | 생성형 AI 연결 및 프롬프트 설계 | Notion 협업 툴 API 연결 | 전체 파이프라인 설계및 시각화 |  
| 스케쥴 트리거<br>(예: 매일 아침 8시 실행) 설정 | 요약 포맷<br>(짧은 헤드라인 + 3줄 요약) 표준화 | 저장 구조 설계 | 모듈 간 연결 테스트 <br>(RSS->AI->Notion) |  
| 주제 필터링<br>(예: "네이버" 키워드만) 정의 | 품질 검중<br>(요약이 정확하고 중복여부 확인) | 메타데이터<br>(출처, 링크) 자동 기록 | 에러 로깅 체계 구축 |  


------------  
## ⭐  시스템 아키텍처  ⭐   
------------  
#### ✅ 노코드 도구 : Make  

#### ✅ 파이프라인 
    
    스케쥴 트리거(매일 아침 8시 정각) ->RSS(2) → 주제 필터링(키워드) -> OpenAI(5) → Notion(8) -> 예외처리  

1. 각 단계별 구조 및 역할

    - Trigger : RSS 수집 (새 정보 도착, 매일 아침 8시 정각)
    - Filter  : 필터링
    - OpenAI  : AI 요약
    - Action  : Notion 기록 (데이터베이스 기록)

1. 주요 기능

     🔹 스케쥴 트리거 : 정기적으로 매일 아침 8시 정각 자동 실행  
     🔹 RSS 자동 감지 : 지정 RSS에서 최신 항목 가져오기  
     🔹 주제 (키워드) 필터링 : 키워드 조건(예:네이버) 만족 항목 1건 선택  
     🔹 AI 요약 (OpenAI GPT-4o-mini)  : 프롬프트 적용, 3줄 요약 생성  
     🔹 URL 자동 정제 및 디코딩  
     🔹 Notion 자동 저장  : 제목/요약/키워드/요약/날짜 매핑 저장
     🔹 예외 처리 : OpenAI 또는 Notion 에러 발생 시 에러알림 메일 발송 및 Resume 처리

### ✅ Filter  

  - 키워드 필터링 : 특정 기업의 투자 관련 정보(뉴스) 수집을 위해 실적, 영업이익, 매출, 배당, 분기, 증권사, 리포트, 분석, 전망, 컨센서스로 한다.  
  - 키워드 기준 및 목록 : 매일 수많은 뉴스가 쌓이는 정보 중에서 "내가 정말 놓치면 안 되는 중요한 키워드"나 "특정 주제"가 포함된 정보들을 요약된 내용을 모아서 볼 수 있는 자동화 프로그램으로, 
                         관심 있는 기업 정보(뉴스)를 요약된 내용으로 받아보고 싶어서 만들었습니다.  
                         투자 관련 정보를 위한 키워드로 실적, 영업이익, 매출, 배당, 분기, 증권사, 리포트, 분석, 전망, 컨센서스를 넣었습니다.

        단순 주가 변동 뉴스나 일반 IT 서비스 소식이 아닌, 기업의 펀더멘털(재무 건전성, 성장성) 과 전문가의 투자 분석에 집중.  
        
    3. 필터링 조건 구조  
        [필수 조건] 제목에 "네이버" 포함  
            AND  
        [선택 조건] 아래 키워드 중 1개 이상 포함

    4. 키워드 필터링 목록   
    🔹 카테고리 1: 실적/재무 관련 (5개)  
       .키워드	선택 이유  
       실적 :	기업의 경영 성과를 종합적으로 나타내는 핵심 지표  
       영업이익 :	본업의 수익성을 판단하는 가장 중요한 재무 지표  
       매출 :	기업의 외형 성장률 및 시장 지배력 파악  
       배당 :	주주 환원 정책 확인, 장기 투자자에게 중요한 정보  
       분기 :	분기별 실적 발표는 주가에 가장 큰 영향을 미치는 이벤트  
    🔹 카테고리 2: 분석/전망 관련 (5개)  
       .키워드	선택 이유  
       증권사 :	전문 애널리스트의 공식 의견 및 리서치 자료  
       리포트 :	심층 분석 자료로 투자 판단의 근거 확보  
       분석 :	다양한 관점의 기업 평가 정보 수집  
       전망 :	미래 실적 예측 및 산업 트렌드 파악

     5. 기대 효과

     - 의사결정 효율성: 투자 판단에 직접 활용 가능한 데이터만 수집  
     - 시간 절약: 하루 수십 건의 뉴스 중 중요 뉴스만 자동 선별

#### 3. 키워드 선택의 논리적 근거  
  
  본 프로젝트의 필터링 키워드는 임의로 선정한 것이 아니라, 
  공신력 있는 기관의 공시 규정 및 실무 표준을 참고하여 도출되었다.
  
##### 3.1. 재무 실적 관련 키워드  
  **대상 키워드**: 실적, 영업이익, 매출, 배당, 분기  
  
     **선정 근거**:
     금융감독원 전자공시시스템(DART)의 정기공시 규정에 따르면, 
     상장기업은 분기별로 매출액, 영업이익, 당기순이익, 배당 정보를 
     의무적으로 공시해야 한다. 이 항목들은 투자자의 의사결정에 
     필수적인 정보로 간주되므로, 관련 키워드를 필터링 대상으로 선정하였다.
     
     📎 출처: 금융감독원 전자공시시스템 (https://dart.fss.or.kr)
  
##### 3.2. 시장 전망 관련 키워드
  **대상 키워드**: 증권사, 리포트, 분석, 전망, 컨센서스
  
     **선정 근거**:
     국내 주요 증권사(삼성증권, 미래에셋증권, KB증권 등)의 
     기업분석 리포트는 공통적으로 '실적 분석', '목표주가 전망', 
     '투자의견', '컨센서스'를 핵심 항목으로 다룬다. 
     또한 한경 컨센서스, 네이버 증권 리서치 등 
     주요 정보 플랫폼에서도 동일한 분류 체계를 사용하고 있어, 
     투자 판단의 표준 지표로 인정받고 있다.
     
     📎 출처: 
     - 한경 컨센서스 (http://consensus.hankyung.com)
     - 네이버 증권 리서치 (https://finance.naver.com/research/)
  
##### 3.3. 재현 가능성
  
  본 키워드 선정 절차는 다음과 같이 재현 가능하다:
  
  1. **공시 규정 확인**: DART 웹사이트에서 '정기공시 항목' 확인
  2. **리서치 항목 조사**: 주요 증권사 리포트 5개 이상 표본 조사
  3. **공통 항목 추출**: 3회 이상 반복 등장하는 핵심 용어 선정
  4. **최종 검증**: 네이버 증권 뉴스 카테고리와 대조하여 정합성 확인
  
  이 절차를 따르면 동일한 키워드 집합이 도출됨을 확인할 수 있다.

### 📌  에러처리  

자동화 툴(Make.com)에서 에러 처리는 **"흐름이 끊기지 않게 하는 것"**과 **"문제가 생겼을 때 알림을 받는 것"**이 핵심입니다.  

------------  

1. 에러 알림 구조 설계
에러가 발생해도 전체 워크플로우가 멈추지 않고, 나에게 이메일을 보낸 뒤 다음 단계로 넘어가는 구조.  

        구조: [에러 발생 모듈] -> [에러 핸들러 경로] -> [Email 모듈] -> [Resume/Ignore]

2. 에러 처리가 가장 필요한 핵심 지점 (Top 2)
  - OpenAI (Generate a completion): 가장 에러가 잦은 구간입니다. (API 호출 한도 초과, 서버 타임아웃, 부적절한 콘텐츠 필터링 등)  
  - Notion (Create a Database Item): 네트워크 오류나 데이터베이스 속성 불일치로 실패할 수 있습니다.

3. 에러 처리 방법
   
        OpenAI 에러 발생 시 → Email 모듈 (나에게 알림) → Resume (기본값으로 다음 단계 진행)
        Notion 에러 발생 시 → Email 모듈 (나에게 알림) → Resume (해당 뉴스 종료)or Ignore (해당 뉴스 건너뜀)

4. 에러 메일 내용

        [Make 에러 알림] 뉴스 요약 워크플로우 오류 발생

        <b>📍 발생 지점:</b> 에러 발생 모듈명<br>
        <b>⚠️ 에러 메시지:</b> {{Error.Message}}<br>
        <b>📰 관련 뉴스:</b> <a href="{{url}}">{{title}}</a><br>
        <br>
        확인 후 조치가 필요합니다.
